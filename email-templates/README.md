# Шаблон письма с кодом входа

`sign-in.html` побайтово восстановлен из полной локальной резервной копии 11 октября 2026 года. Это сохранённый исходник шаблона Supabase Auth: `{{ .Token }}` — место для одноразового кода, а не пример настоящего кода.

Перенос файла не меняет настройки Supabase или Resend и не отправляет письмо. GitHub Actions не загружает его в почтовый сервис и не включает в сайт. Фактический шаблон в Dashboard при этой работе не сравнивался с файлом.

В тексте указан срок действия 10 минут. Перед будущей установкой или изменением шаблона нужно сверить его с реальным сроком OTP в Supabase. Прежние шаги настройки сохранены как [историческая инструкция](../docs/history/AUTH_SETUP.md); они не подтверждают текущие настройки отправителя.
