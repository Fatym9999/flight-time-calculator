# Исходные SQL-материалы журнала

Восстановлены из полной локальной копии 11 октября 2026 года. SQL-тело сохранено без изменений; обновлены только вводные комментарии о назначении файлов. В рамках переноса команды **не выполнялись в Supabase**.

- `sync-setup.sql` — первоначальное создание `flight_journals`, функции проверки записей, правил доступа владельца и RPC `save_flight_journal` с проверкой ревизии и идентификатора запроса. Это начальная схема, а не повторно применяемая миграция: таблица и политики создаются без проверки существования.
- `sync-verify.sql` — прежняя транзакционная проверка ревизий, повторов, валидации и разделения аккаунтов. Она создаёт временные тестовые аккаунты и журналы и заканчивается `rollback`. Это исполняемый тест с записью данных, а не запрос только для чтения; его пригодность для нынешней схемы отдельно не проверялась.

Оба сайта сейчас используют одну базу. Эти файлы сохранены для сверки и подготовки будущих миграций; не запускать их повторно на существующей базе как шаг обычного обновления сайта. Перед любыми изменениями схемы нужно сначала проверить состояние настоящей базы и подготовить отдельную миграцию. GitHub Actions не исполняет эти SQL-файлы и не включает их в опубликованный сайт.

Текущее поведение клиента описано в [руководстве проекта](../docs/README.md), старые подробности — в [SYNC_SETUP.md](../docs/history/SYNC_SETUP.md).
